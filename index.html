  1. Edit the expression in the function card. Fractions, roots, powers and trigonometric functions are supported.
  2. Choose +/−, ↑/↓, or ∪/∩ to color the curve by sign, monotonicity, or concavity.
  3. Drag the graph to pan. Use the wheel or pinch to zoom. Double-click the graph to return home.
  4. Hover on a curve to compare f(x), f′(x), and f″(x) at the same x-coordinate.
  5. Turn on f′, f″, special points, or the tangent line when you are ready to reveal more.
  6. Use Axis scale x:y to compare horizontal and vertical units from 20:1 to 1:20. The graph always fills the whole canvas; the visible coordinate range expands as needed. Use Scale 1:1 to reset quickly.
  7. Use Font size in the top header, from 50% to 300%, to enlarge or reduce text across the interface and graph labels.
  8. Use the chevron in the Functions panel to collapse/expand the left panel, and the chevron on the bottom analysis panel to reclaim more graph space.
  9. The Examples menu can read an external JSON file. You can also build functions with the normal UI and press Export functions → JSON (or Export current inside Examples) to download a ready-to-use examples.json.
  10. Each function card has an independent Example title. Export keeps that title separate from the mathematical function label such as f(x), along with its MathLive LaTeX, analysis mode, f′/f″/Points choices, the current graph range, and axis scale.
  11. Put the exported examples.json beside the HTML when serving it from a web server, or press Load JSON when opening the HTML directly from a computer.

Examples JSON format

Only latex is required. The other fields are optional.
{
  "title": "My M2 examples",
  "examples": [
    {
      "title": "Example 1",
      "function": "f(x)",
      "latex": "x^3-3x",
      "note": "Extrema and inflection",
      "mode": "monotonicity",
      "showD1": true,
      "showPoints": true,
      "range": { "xmin": -4, "xmax": 4, "ymin": -6, "ymax": 6 }
    }
  ]
}
